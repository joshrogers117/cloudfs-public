CloudFS

Self-hosted streaming files for Mac teams. Run the server in your Cloudflare account and access your files in Finder.

Start with copies of files. Test your editing applications and recovery workflow before relying on the preview for production work.

Download app and server

Set up your team

  1. One administrator prepares Workers Paid, R2, Node.js 22.12+ and a temporary provisioning token.
  2. Extract the server package and run its guided installer. It creates the infrastructure and opens browser setup.
  3. Create the first account and filespace, configure email delivery, and invite teammates.
  4. Teammates accept their invitation, install the signed Mac app and sign in through their browser.

Teammates do not need Cloudflare credentials or a setup secret. The server runs on Cloudflare after installation; the setup computer can be turned off.

Your infrastructure

CloudFS uses Workers and Durable Objects for metadata and coordination, and R2 by default for encrypted file blocks. You pay your infrastructure provider directly. The server operator controls the encryption keys and must be trusted.
